# RainGit

Android GitHub & GitHub Actions client. Kotlin · Compose · Material 3 · JGit.

GitHub Actions → **Android Build** → Artifacts → `RainGit-debug`.

登录：PAT 或 GitHub OAuth Device Flow（需自己的 OAuth Client ID，并在 GitHub 启用 Device Flow）。账号密码及 2FA 在 GitHub 官网完成。

本地仓库默认保存于应用目录；访问自选公共文件夹需授予“所有文件访问权限”，支持主存储目录。

要求 Android 11+。仓库操作仅支持 HTTPS Git remote。第三方 Git 服务暂不支持。
